# Author Host runtime v5

This owned component combines the complete author source with the real server
ABI4 and independent Browser-v1 compilation results. Its provider bundles the
maintained Host5 replay and journal implementation. It contains no copied server
worker, TypeScript runtime, browser runtime or third-party dependency tree.

Source and Native permissions are supplied by the owning Core. Stored program
hashes and journal records do not grant publication or browser readiness.
