# Bounded Tavern template runtime

The maintained provider, controller, compiler and worker are NextTavern source
under GPL-3.0-only. Generated ESM modules derive from manifest-owned TypeScript.
The admitted source resources accompany the package; no original card or
third-party helper program is distributed in this component.

The component independently vendors quickjs-emscripten-core,
@jitl/quickjs-wasmfile-release-sync and @jitl/quickjs-ffi-types, all 0.32.0 and
MIT. Their original package metadata, LICENSE files, CJS/ESM modules, complete
published FFI and WASM layouts remain beneath node_modules. The existing locked
library assembler produces that closure without executing lifecycle scripts.
No TypeScript, EJS, Zod, Lodash or MVU executor is a runtime dependency.

assets/runtime.json binds the three executable entries, dependency pins and
template policy. assets/source-inputs.json records the actual bundled source
graphs and their registered package resource identities. The existing product
inventory protects every delivered byte, including this notice and licenses.
These records are data; only the actual product/protected-package owner admits
the component. A checksum of a caller-selected directory grants no permission.

The first admitted generation stays bound to its physical module URL. A changed
generation at that URL requires a new process or a distinct protected-generation
URL. Worker roots and dependency resolution are fixed by the component itself.

The template VM emits bounded plain text and read/activation proposal data.
Core must independently prove current Source, variable namespaces, state,
messages and Native ownership. This component has no schemaGuest, state write,
numerical publication, Session, provider transport or model-request authority.
