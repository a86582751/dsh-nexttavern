# Owned registered-command policy runtime

The NextTavern provider, compiler and runner are licensed GPL-3.0-only.
Generated modules derive from registered canonical TypeScript sources and
contain no third-party card or helper implementation.

This separately admitted package retains ABI4 and binds its new command policy
profile to real author import sites. Only registrations obtained from a fixed
supported StageDog alias discard commands rejected by all applicable StageDog
registrations. Global and handwritten schema-bridge registrations remain atomic.
Retained atomic programs are served by their original protected generation;
their records and assets are not reinterpreted by this package.

The package vendors TypeScript 5.9.3 (Apache-2.0), quickjs-emscripten-core 0.32.0,
@jitl/quickjs-wasmfile-release-sync 0.32.0 and @jitl/quickjs-ffi-types 0.32.0 (MIT),
including their package layouts, WASM and license/notice files. Trusted guest
assets derive from Zod 4.4.3 and Lodash 4.18.1 (MIT), with their license files.

The generated descriptor records comparison data. The existing protected
package inventory admits the complete physical package before execution. A
loaded module URL remains bound to its first admitted generation.

This provider owns package admission and compiler/worker disposal. Core owns
Source, actual Native completion, publication, history and cancellation. No
model request, installation path or upstream helper execution is added.
